What the earlier atlas versions can give the current map

Source and interaction-structure review of 32 prior comparison editions, the separate geographic route, and the current pass-37 baseline (34 routes). No fresh visual browser inspection is claimed.

The ideas below are proposals. Shipped in this pass: a Submit draft form, direct film shortcuts in selected-land results, a direct return to those results, designed film-title fallbacks, this review, and edition-specific comparison links. The master archive is unchanged.

Worth recovering or bringing forward

  1. Searchable place-name tray

    Ribbon, Places, Encounters 01

    An optional tray can make all collected names reachable, including unmapped references, without filling the map with labels.

  2. Watch & read

    Places and the separate Geographic route

    A selected film or reading path can offer a sourced trailer and related reading in one deliberate space. Keep Ak’abal as an attributed reading, with its specific voice, not a generic visual theme.

  3. Island orientation inset

    Shorelines, Places

    Show a small regional reference when deep zoom makes a Caribbean island or its neighbors difficult to locate.

  4. Country quick peek

    Cinema Hover 03, Navigation 04

    A country can preview three filmmaker names and a sample film in the existing margin before the user commits to its full list.

  5. Shared-reference next steps

    Interactive 26, Density 29; still present in current adjacentDetail

    Show a few related records after a profile, labeled by their actual shared land references. This is navigation evidence, not an inferred collaboration or identity equivalence.

  6. Selected drawn paths

    Linework, Encounters 01, Constellation 05

    Keep the expressive curve in one selected relationship or short path. Maintain precise endpoints, numbered references and sourced/provisional styles; avoid borrowing culture-specific motifs as decoration.

  7. Task-oriented lists

    Research 27; still present in current listDefinitions

    Bring a few existing lists into view when relevant: screening/watch pages, affiliation sources checked, named collectives, or no mapped area. Many useful capabilities are hidden rather than absent.

Substantial flow suggestions

Start with priorities 1–3: one visible journey path, cross-heading search, and a continuous land-to-film route.

  1. One visible journey path P1

    Replace competing Back/land/detail controls with Land → selected reference → filmmaker → film. Every crumb restores its own camera, filters, result page and scroll.

    How to judge success

    User can return two levels without clearing the search or reopening the wrong list.

  2. One query, three explicit result types P1

    Show Filmmakers / Films / Land match counts for the same query. Let the user switch the result type without retyping; retain the three primary headings.

    How to judge success

    A title typed in Filmmakers offers a direct Films result instead of a dead end.

  3. Keep discovery within the selected land P1

    From a land, offer its filmmaker list and film list as paired, scoped choices. Direct film shortcuts are added in this pass; a broader shared-reference next step after a film remains proposed.

    How to judge success

    Land → filmmaker → film → another linked filmmaker is a continuous route with a visible return.

  4. Explain the active scope P1

    A compact scope line states country/land, query and active filters. Release each independently; distinguish full country totals from the current result count.

    How to judge success

    User can explain why a list is short and widen it with one action.

  5. Put shared-reference discovery where a profile ends P1

    Surface three relevant filmmakers beneath the selected record, with the common reference and source/provisional status stated.

    How to judge success

    The next record can be opened without expanding a hidden evidence section; no claim of collaboration is implied.

  6. Offer image browsing as a deliberate mode P2

    Use the existing film previews as the entrance to a thumbnail grid, alongside a compact text list. Keep 20-credit pagination and exact roles.

    How to judge success

    User can browse by image and return to the same film/page; missing images use title cards.

  7. Give camera movement its own undo P2

    Keep automatic land focus, add a small return-to-previous-view action, and consider an optional camera-follow toggle for sustained profile comparison.

    How to judge success

    An unwanted camera move can be reversed without undoing filters or closing the profile.

  8. Make missing geometry a complete reading route P2

    An unmapped name opens its context, source and linked records with equal prominence, plus an explicit map-return action. A small reference diagram could support comparison.

    How to judge success

    Every indexed name is usable without a fabricated polygon, centroid or personal location.

  9. Use a contextual name tray P2

    Open a searchable, nonmoving strip of collected names on request. Suggest names related by the chosen country/source index, with the relation labeled.

    How to judge success

    User can find Ixim Ulew or another supplied name even if it has no visible map label.

  10. Add regional orientation when it is needed P2

    Bring in the earlier Caribbean inset only for an island selection or very deep zoom. Clearly distinguish the inset from the selected source geometry.

    How to judge success

    A user knows where they are without zooming all the way out and losing the selection.

  11. Separate reading from map following on phones P2

    Offer a clear Map / Reading switch that preserves both positions, and keep the current profile/film visible on return.

    How to judge success

    A film can be read, its reference located, and the same reading position resumed without a long scroll.

  12. Build a temporary reading queue P2

    Let users hold a handful of filmmakers/films for side-by-side reading, then save a named path. Add export/import for browser-local saved paths.

    How to judge success

    An exploration can be resumed on another device without making the master catalog editable.

  13. Make the viewing decision explicit P2

    Present full-film page, trailer, festival/information page and any recorded access condition as distinct actions. Audit thumbnail sources before expanding coverage.

    How to judge success

    User can identify the kind of destination before clicking; a screening page is not labeled as guaranteed free playback.

  14. Turn Submit into a reviewed contribution flow P3

    Later, open submissions from a selected record with explicit context, source/evidence fields and a review queue. Keep received suggestions separate from the stable catalog.

    How to judge success

    A contributor sees what was received and its review status; no suggestion silently changes the archive. This pass provides only the draft shell.

  15. Make keyboard and touch a complete journey P2

    Support result-list movement, explicit select/return focus, a searchable overlap chooser, and consistent one-layer Escape. Verify these on a real phone and keyboard when browser access is available.

    How to judge success

    The same Land → filmmaker → film → Back path can be completed without pointer precision or accidental map resets.

The Submit entry point

Submit is in the atlas header. The draft form supports a filmmaker, film, land name or correction, with optional affiliation, source and notes. Review draft and Copy draft work locally. Actual submission is marked as coming soon; nothing is sent to the atlas or inserted into the archive.
