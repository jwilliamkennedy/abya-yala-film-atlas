# Globe relief asset

`beta/assets/globe-relief-hyp-50m.png` is the 1000×500 Natural Earth HYP_50M_SR raster distributed by [riatelab/geoviz](https://github.com/riatelab/geoviz/blob/main/earth/small/HYP_50M_SR.png), source Git blob `dae831f02332dab72a2caaf8839e51607ae88926`. Original dataset: [Natural Earth cross-blended hypsometric tints with shaded relief](https://www.naturalearthdata.com/downloads/50m-raster-data/). Natural Earth data are public domain. This low-resolution image provides physical relief at global and continental scales, not street-scale terrain or an elevation measurement. The existing Natural Earth vector coastline clips the raster; all Indigenous reference polygons and film anchors remain unchanged. Territory colors are deterministic display distinctions, not cultural or legal classifications. WebGL failure leaves the original vector land visible. No remote image request occurs at runtime.
