# Boundary presentation and discovery pass — 24 Nov 2026

Default presentation retains translucent fills for every territory and emphasizes only the selected/previewed land boundary. Land visibility settings permit no outlines or all outlines for inspection. The fill layers explicitly disable their implicit outline colors. This is a rendering-only change, not geometry correction. Offline QA reports source edges over 500 km rather than treating long edges as erroneous. Browser QA checks actual layer visibility in each mode.

Discovery avoids the ten recent lands when alternatives exist and excludes another credit for the same film from thematic bridges. A point index removes repeated linear lookups.

Its data-sovereignty treaty (https://api-docs.native-land.ca/data-sovereignty-treaty) requires explicit permission for API redistribution and community consultation for boundary changes. The historical source remains labeled; no new polygon data were downloaded. A direct partnership/permission review is necessary before refreshing the dataset.
