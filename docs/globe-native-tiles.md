# Native tiled globe — 24 November 2026

Beta uses vendored MapLibre globe projection for satellite, DEM hillshade, existing reference polygons and cinema anchors. At high zoom MapLibre transitions to a local Mercator view; all layers share its camera. Fallback remains the local orthographic canvas. The configured WMTS layer is s2cloudless_3857 (2016 release, containing 2016–2017 Sentinel data). The provider identifies this release as CC BY 4.0, not the 2018–2025 CC BY-NC-SA releases. Visible attribution and detailed source page: beta/map-sources.html. See https://cloudless.eox.at/license-non-commercial. Terrain tiles: https://mapterhorn.com/attribution/. No API key. Satellite resolution is Sentinel-2, not proprietary sub-meter aerial photography. Source availability and latency depend on external services. No boundaries or catalog records changed.
