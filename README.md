# Indigenous Cinema Atlas: Abya Yala and Turtle Island

A map of Indigenous filmmakers and their lands across the Americas, by John Kennedy Godoy.

Public site: https://jwilliamkennedy.github.io/abya-yala-film-atlas/

## What's here

- The repository root is the published site. It is an exact copy of the ChatGPT-hosted edition (site version 66, checked file by file against the live site on 31 October 2026).
- `source/` holds the build scripts, research data and project notes from that edition. Private research layers are not included.
- `beta/` (coming) holds the next edition for review before it replaces the main site.
